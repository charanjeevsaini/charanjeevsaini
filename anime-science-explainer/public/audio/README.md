# Audio

| Path | What | Required? |
|---|---|---|
| `voice/*.mp3` | Character dialogue, generated by `npm run tts` (Kokoro TTS) | No – lines without audio play silently with subtitles |
| `bgm.mp3` | Background music, looped at low volume (12%) with fade in/out | No |
| `sfx/whoosh.mp3` | Scene wipes, ray/photon moves | No |
| `sfx/sparkle.mp3` | Professor's entrance, title, "illusion!", end screen | No |
| `sfx/impact.mp3` | Shock moment, flash transitions, power-up slams | No |
| `sfx/pop.mp3` | "!" / "?" pop-ups, cards appearing | No |
| `sfx/powerup.mp3` | Start of the power-up scene | No |
| `sfx/splash.mp3` | Pencil dropping into the glass | No |

Drop royalty-free MP3s in with exactly these names and re-render; nothing else
needs to change. Missing files are detected with `getStaticFiles()` and skipped,
so the video always renders.
